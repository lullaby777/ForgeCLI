- 运行编号：
- 日期与时区：
- 起始源码快照/提交：
- Python 和依赖清单位置：
- 模型名称及服务商（不含密钥）：
- 模型配置、执行上限（见 metadata.json）：
- 运行前原有测试：通过 / 失败 / 未运行
- 运行前外部验收：失败（附输出）/ 其他
- Agent 执行：正常返回 / 异常 / 中断 / 达到上限
- 运行后外部验收：通过 / 失败 / 未执行（附输出）
- 运行后原有测试：通过 / 新增失败 / 环境问题 / 未执行
- 是否修改已有测试：
- 最终判定：通过 / 修复未通过 / 违反约束 / 环境问题 / 中断
- 耗时、输入输出 token、费用估算（未知写未知）：
- 补丁及新增文件位置：
- 主要失败现象和证据（不要猜测模型的内部原因）：
- 是否有人为追加提示或修改（有则不能当作同一次无干预基线）：
