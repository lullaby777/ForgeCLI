修复 CoreCoder 的会话文件容错问题。

复现：在会话目录保存一个正常会话，再加入内容为 [] 的 JSON 文件。
加载这个坏会话或列出所有会话会抛异常，正常会话也因此无法展示。

要求：
- load_session 对格式或结构无效的会话返回 None。
- list_sessions 跳过无效会话，继续展示正常会话，不删除或改写坏文件。
- 最低有效结构为：顶层对象、非空字符串 model、列表 messages；
  每条消息是对象，role 是非空字符串，content（如果存在）是字符串或 null。
- 缺少 model/messages、字段类型错误、无效消息项、非法 JSON、非法编码均应安全处理。
- 空 messages 有效；assistant 的 content 为 null 且带 tool_calls 的历史有效。
- 保持现有函数接口、中文保存、会话预览与路径防护行为。

请阅读代码、修复并运行相关测试。可以新增开发测试，不得修改或删除已有测试。
不要读取真实用户的会话目录，不要修改外部验收材料。
完成后说明修改内容、测试结果及未解决的问题。
