修复命令工具和文件工具对当前目录的理解不一致的问题。

复现：临时根目录有 note.txt（ROOT VALUE），子目录 backend 中也有 note.txt（SUB VALUE）。
命令工具成功执行 cd backend 后，bash 的 cat note.txt 返回 SUB VALUE，
但 read_file("note.txt") 仍读到 ROOT VALUE；edit/write 也可能操作错误的同名文件。

要求：
1. 相对路径统一以当前会话记录的目录为准：read_file、edit_file、write_file、grep、glob。
   grep/glob 不传 path 时也按当前会话目录搜索；显式相对目录和文件同样适用。
2. 编辑和写入仅操作正确目录，不能碰根目录同名文件；支持在当前目录下创建嵌套文件。
3. 保持绝对路径和 ~ 的原有含义；没有会话目录记录时，仍回退 Python 进程当前目录。
4. Agent 并行批次中的所有工具继承批次开始时的目录，不受同批其他工具的 cd 完成时机影响。
   批次结束后按已有规则合并 bash 目录变化，后续文件工具使用合并后的目录。
5. 保持线程、父子 Agent 的目录隔离，禁止通过 os.chdir 改变 Python 全局目录来解决。
6. 保持现有接口、文件工具安全检查、输出格式与原有回归兼容；可新增测试，不修改或删除已有测试。
7. 本题只用成功的 cd，不修复第四题组合命令失败目录跟踪。不带入其他四题或空回复问题修复。
8. 开发测试使用临时文件和假模型，不调用真实模型；不读取或修改原项目 baseline 外部验收材料。
9. 已有 README 总行数失败不处理；本次改动使具体文档行数引用失效时可同步，不改测试放宽标准。
