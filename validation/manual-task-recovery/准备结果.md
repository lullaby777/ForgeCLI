# 长任务暂停恢复：手动验证准备结果

正式目录 `/tmp/corecoder-task-manual-01`，工作区 `workspace`，运行时 `runtime`，任务配置 `task.json`，隔离会话目录 `home/.corecoder/sessions`。
运行时与当前主项目逐文件一致，依赖通过独立虚拟环境离线复制安装并核对固定版本。没有调用真实模型，没有修改主项目代码。

起点仍使用第四题原始未修复代码。修复前验收 14 项中 9 项失败；原有回归 352 通过、1 个已知 README 行数失败。正式任务、会话和暂停标记都尚未创建，留给手动验证。

## 已完成的离线演练

在一次性临时副本中，使用模拟提供方走过实际 CLI：/repair 创建任务 → 真实 read_file 工具结果落盘 → 安全窗口模拟 Ctrl+C → 退出 → -r 原会话 → 输入“继续任务”。
演练中暂停前占用 1 次调用；仅打开会话时账本完全不变；继续后累计 3 次脚本调用。任务编号、原始失败清单和基线文件哈希保持一致，单个会话链接一直指向同一个任务。
模拟模型故意不修复候选问题，最终按无进展停止，证明没有因为恢复就误报完成。此演练验证恢复机制，不证明真实模型能修复第四题。

缺少密钥时启动器拒绝开始。脚本 lint 通过。五个基线、v1/v2/v3/v4、此前续跑副本、baseline 和已有 validation 结果均核对未变。

## 手动操作顺序

1. 终端已有有效 CORECODER_API_KEY 后启动：

```sh
/tmp/corecoder-task-manual-01/venv/bin/python /tmp/corecoder-task-manual-01/scripts/launch.py
```

在 You > 输入：

```text
/repair /tmp/corecoder-task-manual-01/task.json
```

2. 等待“安全暂停窗口”提示，按一次 Ctrl+C。回到 You > 后输入 /task，再输入 quit。

3. 在终端保存暂停快照，不调用模型：

```sh
/tmp/corecoder-task-manual-01/venv/bin/python /tmp/corecoder-task-manual-01/scripts/check.py --snapshot paused
```

4. 打开原会话：

```sh
/tmp/corecoder-task-manual-01/venv/bin/python /tmp/corecoder-task-manual-01/scripts/launch.py --resume-last
```

--resume-last 只选择绑定本任务的唯一会话，不会自动继续。也支持 --resume 显式会话ID。
保持该窗口在 You >，暂时不输入“继续任务”，在第二个终端运行：

```sh
/tmp/corecoder-task-manual-01/venv/bin/python /tmp/corecoder-task-manual-01/scripts/check.py --snapshot restored
```

应显示 comparison_to_paused=passed：打开会话前后任务 ID、整个账本、失败基线和基线文件哈希都完全一致。

5. 回到第一个窗口输入“继续任务”。完成或停止后用 /task 查看，再 quit。在终端保存结束记录：

```sh
/tmp/corecoder-task-manual-01/venv/bin/python /tmp/corecoder-task-manual-01/scripts/check.py --snapshot finished
```

调用、尝试及累计时间不应减少；同一次尝试轮数不倒退，进入新尝试时当前轮数可重新计数。调用上限 30、尝试上限 3、每次轮数上限 10。
如果已有代码恢复后直接验收合格，允许不新增调用。不要为了让计数增长而继续发提示。
原始失败清单及基线文件哈希应保持不变。最终是否完成以 completed、目标验收和回归共同判断，不以“恢复命令执行成功”代替修复成功。

## 记录和边界

snapshot 各名称只写一次，不覆盖；不带 --snapshot 的 check.py 随时只读查看。
暂停/恢复/结束记录在 records；权威任务记录在 task/state.json、task/baseline.json；会话链接在隔离 home 下。
安全暂停窗口只是本次启动器里的辅助钩子：正式检查点保存完成后才等待按键，不在在途模型或工具上中断。只触发一次，恢复后不再等待。
如果请求报错、窗口未出现或状态不符，保留现场，不手工编辑预算、基线或重建任务目录。

完整逐步说明见 scripts/README.md；准备结果元数据见 prepared.json，离线交互输出见 offline-cli.txt。
