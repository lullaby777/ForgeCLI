# 独立验收闭环验证

当前项目实现外部控制器、固定本地验收、失败反馈、有限续跑与结构化结果，未调用真实模型。

- 403 项离线测试全部通过，其中新增 27 项闭环回归。
- 离线演示：错误写入 → 本地验收失败 → 反馈后修复 → 验收通过；2 次执行尝试、4 次模拟模型入口调用。
- 五个基线及原始记录 683 个受保护文件哈希未变化；已有测试没有修改。
- 本次修改文件静态检查及编译检查通过。全仓仍有 6 条已有工具告警。
- 结果目录需新建，不覆盖旧证据；日志保留 Agent 执行状态、代码指纹、退出码和验收输出。
- 超时检查是调用边界协作式；不能强杀已发出的模型请求或任意 Agent 工具。验收子进程有超时终止。
- 模型调用上限不含客户端内部 HTTP 重试，不是严格美元预算。
- 哈希保护不是沙箱，不能防止恶意修改后恢复；固定验收的质量仍由调用方负责。

演示 JSON、事件和两次验收日志已另存于本目录 demo-*。这证明本地编排机制，不证明真实模型修复成功率提升。
使用与配置见 docs/repair-loop.md。
